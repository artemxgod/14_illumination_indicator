# illumination indicators shows level of illumination using leds

## Функция `map(val, MIN_LIGHT, MAX_LIGHT, 8, 0)` преобразует значение с A0 (200–900) в число светодиодов (4–0): при ярком свете — больше светодиодов, при слабом — меньше. constrain() ограничивает значение диапазоном 0–8. В цикле зажигаются светодиоды с номерами от 1 до val, остальные гаснут. Резисторы 10 кОм ограничивают ток через светодиоды.
